### Processing & Optimization:
- Resized and re-compressed using high-quality bicubic filtering to target crisp display while keeping total image weight under ~850 KB across all four high-resolution photos.
- Configured with `object-fit: cover` and preserved aspect ratios (21:9 hero, 16:10 destination cards).
